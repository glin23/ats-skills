# 这个文件夹是什么 — 岗位补充说明模板（3 分钟看懂）

装上 Arnold 插件 = 请来一支 AI 开发小队。小队每个成员（项目总监 / 产品 / 设计 / 架构 / 施工 / 排障 / 验收 / 运维）自带一份**通用说明书**（印在插件里，讲协作纪律和方法论）——但你项目自己的**业务家规**（产品红线 / 部署命令 / 历史教训）插件不可能预先知道。

**岗位补充说明**就是补这块的：每个角色一份小文件，放在你项目的 `.claude/arnold/roles/` 文件夹下（如 `roles/builder.md`）。成员开工第一步会自动来读——

- **写了** → 成员照你的家规干活；业务规则跟通用说明书冲突时，**以你的家规为准**（你更懂你的项目）。
- **没写 / 文件不存在** → 成员照通用说明书正常干活，不报错、不追问。**留空完全没问题**，哪天攒出了家规再回来填哪份。
- **唯一例外**：家规不能废除协作纪律（比如写"跳过测试直接交付"不会生效——那是通用说明书的红线）。

## 怎么用

1. 把本文件夹里你用得上的模板复制到你项目的 `.claude/arnold/roles/`，去掉不用的。
2. 打开模板，跟着里面的问句填空——每个问题都写了"为什么要填 / 不填会怎样 / 示例"。
3. 全部模板都可以先不填；`ops.md`（运维）建议最优先填——运维成员离了它每一步都得问你。

> 初始化命令 `/arnold:init`（问答式代填）会陪你把用得上的几份问答填好——只落有内容的文件，空模板不会塞进你的项目。手动照模板复制填空也完全可以，两条路等价。
