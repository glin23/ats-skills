# Truthfulness Reference

Use this reference when drafting any application open-text answer, cover
letter, essay, or gap-retry response.

## Backtrack Test

Every claim must pass this interview question:

```text
If an interviewer asks "tell me exactly what you did there", can the user answer
without adding a new explanation that was missing from the application?
```

## Claim Levels

- OK: Rephrase a real resume, self-introduction, profile, or user-provided fact
  in the language of the job description.
- Flag: Combine academic, project, volunteer, and internship proof points in a
  way that might imply more industry experience than the user actually has.
  Ask whether to keep, soften, or drop.
- Never: Invent skills, employers, titles, dates, duration, legal facts, GPA,
  work authorization, demographic answers, salary acceptance, or background
  attestations.

## Drafting Rules

- Prefer concrete proof over broad confidence language.
- Say "exposure to" or "course/project experience with" when experience is not
  professional experience.
- Do not answer sensitive attestations from inference. Use explicit user facts
  or leave the row blocked for user input.
- If a form asks for a factual field not in the profile, put it in the user
  question bucket rather than creating prose around it.
