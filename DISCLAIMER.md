# Disclaimer

Read this before using `ats-skills`.

## Purpose

This project is a personal learning tool. It exists because the author was filling out a lot of job applications by hand and wanted to spend less time on repetitive form fields. It is shared publicly so other people can do the same with their own job applications.

It is not a commercial product. It is not a service. It is not sold, hosted, or operated for anyone else. There is no business model behind it.

## What you are responsible for

When you use `ats-skills`, you are responsible for:

- Reading and following the terms of service of every ATS platform you interact with, including Greenhouse, Ashby, and any others. This tool does not check those for you.
- Reviewing every form before you submit it. The skill stops before submit. The submit click is yours.
- Only applying to roles you actually want and are actually qualified for. This tool exists to save time on typing, not to help you spray applications.
- Following any "do not contact" or "do not apply" instructions a company or recruiter has given you.

If a platform you use changes its terms, the new terms apply, even if this README has not been updated.

## What this tool does not do

- It does not bypass anti-bot systems. It drives a real Chrome instance under your own profile. It does not spoof TLS fingerprints, rotate IPs, solve CAPTCHAs, or impersonate other users.
- It does not scrape jobs. You bring the URL.
- It does not mass-apply. It processes one URL at a time.
- It does not auto-submit. The skill is designed to pause before the submit button and require explicit per-application confirmation from you. Do not modify it to remove that pause.

## If a platform asks you to stop

If Greenhouse, Ashby, or any other ATS contacts you and asks you to stop using automation against their service, stop. Delete your local copy. Open an issue on this repository so others know.

The author will also stop development if asked by an affected platform.

Do not use this tool to:

- Apply to jobs on behalf of someone else without their authorization.
- Submit fraudulent information.
- Test, probe, or attack an ATS platform's infrastructure.

If you are not sure whether something you want to do is misuse, the answer is probably yes.

## In short

Use this tool the way the author uses it: for your own job search, one application at a time, with your own eyes on every form before it goes out. Anything beyond that is not what this is for.
