## 🚨 开跑之前，先看这一条

**拿到别人简历之后，代跑必须做到三件事：**

1. **用隔离目录跑**（命令前面加 `MRWEIRDO_HOME=/tmp/concierge-张三`），不要跑进你自己的 `~/.mrweirdo-jobs/`——否则你自己的库会被别人的数据盖掉。
2. **只跑到"打分排序"为止**（Step 4 结束）。**不要进 Step 5 队列关卡，不要跑 `--real`。**
3. **一条投递都不许发出去。** 对方没授权过你用他的名字对外投递，这是不可撤销的。

**⚠️ 而且：隔离目录这个跑法，现在正在被 verify 实测，结论还没出来。**
**在我明确回你"隔离跑法实测通过"之前，不要拿任何一份真人简历开跑。**
访谈可以现在就开始约、现在就聊——**只是最后那一步"我帮你跑一下"，先说"这两天给你"，别当场跑。**

## 1. 约人时发的那条消息（直接复制粘贴）

### 中文版（发给中国留学生）

> 在忙吗？想请你帮个小忙——我最近在琢磨大家找实习到底是怎么找的，想找几个人聊 20 分钟，听你讲讲你上一轮具体是怎么投的、卡在哪。
> 不推销任何东西，也不用你准备什么，就是聊。这周有空吗？

### 英文版（发给美国本地学生）

> Hey — can I borrow 20 minutes? I'm trying to understand how people actually go about finding internships, and I'd love to hear how your last round went: what you actually did, where you got stuck.
> Not selling anything, nothing to prepare. Free sometime this week?

**为什么这么写**：如果开口就是「我做了个工具你试试」，对方一定回你"好啊听起来不错"，然后消失。而且从那一秒起，他后面说的每句话都会开始迁就你，你就再也听不到真话了。

### 见面头 30 秒说什么

> 「谢谢啊。就 20 分钟，我不讲我在做什么，主要想听你讲。
> 你随便说，说得越具体越好——不用照顾我的感受，我最怕的是你讲得太客气。」

**这三句一句都别省。** 最后半句是最有用的那半句。

## 2. 八个问题（逐字问法 + 这题在测什么）

> **贯穿始终的一条规矩**：**只问已经发生过的事，不问"你会不会"。**
> 问"你会不会用"，人人都会说"会"——因为说"会"最省事、最不伤感情。这种答案一文不值。

**Q1**
> 「你上一轮一共投了多少家？」
> 追问：**「这个数你是怎么知道的？」**

*这题在测*：他到底有没有在记账。如果他张口就说"大概吧，没数过"——那我们做的报告、看板这一整块，可能压根不是他的痛处。

**Q2**
> 「带我过一遍你**最近一次**投递吧——从你看到那个岗位，到你按下提交，中间都发生了什么？大概花了多久？」
> 追问：**「中间有没有哪一步你停下来过？」**

*这题在测*：真实流程里最费劲的那一步到底在哪。注意听他停顿的地方，不是听他总结的地方。

**Q3**
> 「那次你用了什么？表格？备忘录？还是哪个网站？」
> 追问：**「能现在打开给我看一眼吗？」**

*这题在测*：**看他的屏幕，别听他的描述。** 人对自己的习惯记得很不准。他真打开的那个东西，才是他真在用的东西。

**Q4**
> 「你投完之后，怎么知道对方到底收到没有？」
> 追问：**「你上一次收到真人回音是什么时候？什么形式的？」**

*这题在测*：我们最大的一个黑洞——投出去有没有回音，我们至今一条都没记录过。如果他对这题也一脸茫然、或者反而很在意，都是重要信号。

**Q5**
> 「上一轮有没有哪一次，你开了个头但没投完？卡在哪一题上了？」

*这题在测*：我们最强的那个能力（把各家表单里问过的东西归并起来一次性问你）到底对不对得上真实的痛。他要是想不起来任何一次卡住，那这个能力可能是我们自己给自己找的活。

**Q6**
> 「你为找实习花过钱吗？花在什么上？大概多少？」

*这题在测*：他愿不愿意为这件事付出代价。**注意：只问花过的钱，不要问"你愿意付多少"**——后者的答案全是编的。

**Q7**
> 「有没有用过那种自动帮你投的工具？」
> 用过的追问：**「后来为什么不用了？」**
> 没用过的追问：**「你身边有人用吗？他们怎么说的？」**

*这题在测*：两件事——一是这类工具的真实口碑，二是**用这种工具会不会让人觉得丢脸**。第二件事我们从来没考虑过，但它可能决定他敢不敢跟同学说自己在用。

**Q8**（唯一一道"假设题"，放最后，答案只当参考不当证据）
> 「有一个东西替你把表全填好，但**你自己按提交**；另一个连提交都替你按了。这两个你分别什么感觉？」

*这题在测*：他对"机器替我做决定"的接受度。**但因为这题问的是想象不是经历，他的回答只能参考，不能当依据。** 别在这题上追问太久。

## 3. 现场记录表（一边聊一边填，照抄这张空表）

> **只记三样。别记你的分析、别记你的想法，那些回来再写。**

**受访人**：______　**日期**：______　**他在找什么**：______

| # | ① 他的原话（**逐字抄，别润色**） | ② 他打开给我看的东西 | ③ 我猜错的地方 |
|---|---|---|---|
| Q1 | | | |
| Q2 | | | |
| Q3 | | | |
| Q4 | | | |
| Q5 | | | |
| Q6 | | | |
| Q7 | | | |
| Q8 | | | |

**第 ③ 列是这张表里最值钱的一列。**
聊之前你心里一定有个预期（"他肯定会说填表太烦"）。凡是他讲的跟你想的不一样的地方，当场记一笔。
一场聊完，③ 列一个字都没有 = **这场大概率白聊了**——不是他没说，是你只听见了自己想听的。

## 4. 三条速查卡：听到什么话 = 命中

> 每聊完一场，对着这三张卡打钩。**聊满 5 个人再一起看，不要聊完一个就下结论。**

### 卡 H1 —— 「他的痛到底是投得不够多，还是投了没回音」

**听到这些话 = 命中**：
- 「多少家？没数过 / 大概吧」
- 「我投得够多了，就是没人理我」
- 「投了一百多个，一个回复都没有」

**5 个人里有 3 个命中，意味着**：我们现在最想干的那件事（把 292 个存量投完、提高投递量）**方向就是错的**。他要的不是投得更多，是投出去有回音。

### 卡 H2 —— 「他敢不敢让机器替他按提交」

**听到这些话 = 命中**：
- Q8 那题他明显犹豫、皱眉、说"这个有点吓人"
- 「我朋友用过那种，后来简历被拉黑了 / 投得乱七八糟」
- 「那不就是海投机器人吗」

**5 个人里有 3 个命中，意味着**：这个产品最核心的那一步（替他按提交）可能是负资产。这是产品方向级的大事，**要拿回来重新拍，不要自己在现场改口**。

### 卡 H3 —— 「拦住他的到底是门槛高，还是根本没人知道」

**听到这些话 = 命中**：
- Q3 里他打开的是浏览器插件、Notion、自己搭的表格（说明他愿意学新工具）
- Q6 里他真花过钱（改简历、内推、会员）

**5 个人里有 3 个命中，意味着**：门槛不是主要问题——**他们愿意折腾，只是不知道有这东西**。那第一件该做的事就从"把安装做简单"变成"让人知道有这东西"。

### 两条收工规矩

- **同一句抱怨从 3 个不同的人嘴里出来 = 这条算数了**，不用再追问这一点。
- **5 个人之间一条共同的抱怨都没有 = 不是"没需求"，是人找错了**。换一批人重来一轮，**不要在这 5 个人身上继续加问题**——加问题只会得到迎合。
- **记录时只有三种结果：是 / 否 / 这题没聊到。** 「没聊到」千万不要事后凭印象写成「否」——那是我们代码里刚踩过的坑，换到笔记本上一样会踩。

## 5. 聊完之后那句话（逐字稿，一个字不改）

> 「对了，还有个事——我在做一个东西，帮学生找对口的实习岗位。
> 你要是愿意，把你简历发我，我这两天跑一下，给你一份排好序的岗位清单，每一条都写清楚为什么推荐你、或者为什么给你跳过了。
> **我不会替你投任何东西**，你自己看，觉得哪个不错你自己去投。
> 你觉得没用直接跟我说没用，对我更有帮助。」

**「我不会替你投任何东西」这一句必须在场，不许省。** 它是对方肯把简历给你的唯一理由。
最后一句也别省——它在提前给对方一个说真话的许可。

**清单发回去之后，只问三个问题**：
1. 「这里面哪几条你**本来就打算投**？」
2. 「哪几条**明显不对**？」
3. 「如果这份清单每周一早上自动发到你手机上，你会看吗？」

---

## 附：这一整套的成功标准是什么

- **不是**"他说这个挺好的"。
- **是**：5 个人里至少 3 个人，用**他们自己的话**，说出了同一个难处；并且至少有 1 个人拿到清单之后，主动指出里面哪几条对、哪几条不对。

第一次有人愿意用，多半是看你面子。**第二次他自己回来找你，那才算数。**
