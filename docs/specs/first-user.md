## 拍板人的目标（原话）

> 「我希望做的这东西最后能有人用，现在我感觉不会有人用。」

后续所有排序以「能不能让人用起来」为第一判据（2026-07-23 关卡 1 起生效，2026-07-26 关卡 4 重申）。

## 诊断：为什么现在不会有人用

**一句话：第一分钟里没有一个字是关于他的。** 产品在证明任何事之前，先索要四项依赖、一份简历、
和「以你的名义对外投递」这一整个赛道最重的一次信任授权，把回报推到 20-40 分钟之后。
**风险前置、价值后置**，这条曲线没人会走完。

五个产品层面的病因（不是技术缺陷清单）：

1. **信任曲线是反的** —— 最贵的一次索取放在最便宜的那一秒。
2. **首次价值兑现 20-40 分钟**（对照数字为 C 级，方向可参考）。
3. **没有任何一档「先看看」** —— `--dry-run` 零件已在 Step 5 跑着，只是没做成用户看得见的入口。
   与蓝图第五节「不是功能缺失，是接线缺失」同病。
4. **README 全英文，运行界面中文优先**（`SKILL.md:63-79` 自称 CN-leaning）——
   两个人群里必有一个在第一分钟被劝退，**而我们从没决定过是哪一个**。此条属内部矛盾，不需访谈即可确定。
5. **用这东西本身有社交成本** —— 唯四的真实差异点（不碰 LinkedIn/Indeed、数据不出本机、
   相关性门控、不编造事实）全压在免责声明里当风险提示用。第一个真实用户几乎必然是创始人熟人，
   他愿不愿意用，一半取决于他敢不敢跟别人说自己在用。

## 拍板的方案：人肉门房版首跑（关卡 5，2026-07-26）

**把第一次接触从「你去装」改成「你把简历发我，我跑一下，给你一份带理由的岗位清单」。**
零代码改动，本周可做，创始人本人执行。

1. 先做访谈（8 问，只问过去发生的具体行为），**不提自己的产品**。
2. 访谈结束后才提出代跑，**必须说出「我不会替你投任何东西」**。
3. 用隔离家目录跑（`MRWEIRDO_HOME=/tmp/concierge-<代号>`），**只跑到 Step 4 打分排序为止**，
   不进 Step 5 队列关卡、不跑 `--real`、**一条投递都不许发出去**。
4. 清单发回后只问三题：哪几条你本来就打算投 / 哪几条明显不对 / 每周一自动出现你会看吗。

**代价已认账**：不可规模化；它兑现的是「有人看到价值」（M0），不是「有人自己跑起来」（M1），两级不混算。

**🔴 当前阻塞（未解除）**：隔离跑法**尚未实测**——pm 只读了 `shared/paths.mjs:37`，无命令行。
已派 verify 实测「档案 / 简历 / 求职信 / 截图 / 数据库 / 日志 / 留痕有没有任何一样会漏回创始人真实家目录」。
**实测通过前，不许拿任何一份真人简历开跑。** 访谈可先约先聊，那部分零风险。

## 三条可证伪判据（5 人里 ≥3 命中即认为假设被推翻）

| | 现有假设 | 推翻后产品该怎么变 |
|---|---|---|
| **H1** | 痛点是投得不够多 / 填表太慢 | 主轴从吞吐转向**回音与质量**；「吞吐是最大杠杆」当场作废 |
| **H2** | 学生愿意让机器**以他的名义按提交** | 退到「帮你填、你点提交」那一格——**但那正是 career-ops 占着的位置**，差异化要重打，**属产品方向级决策，须拍板人拍** |
| **H3** | 装机门槛是主要障碍 | 门槛是认知问题不是意愿问题，第一件事从「降门槛」改成「分发 + 首屏叙事」 |

**样本判据**：5 人之间没有任何共同痛点 = 不是「没需求」，是**选错了人群**——换一批重来，
**不许在同一批人身上继续加问题**（加问题只会得到迎合）。

**记录纪律**：每条判据只记 **是 / 否 / 没问到** 三态。**「没问到」绝不许当成「否」**——
这正是 PROJECT_MEMORY 原则 2 在笔记本上的版本，而且没有任何测试会抓到它。
