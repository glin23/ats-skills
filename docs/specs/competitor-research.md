## 赛道按「谁点提交」分四格

| 格 | 玩法 | 代表 | 状态 |
|---|---|---|---|
| ① | 帮你填表、**你自己点提交** | Simplify Copilot、LinkedIn 自营 Apply Assistant（2026-06 上线）、career-ops | 最健康 |
| ② | 云端全自动代投 | JobCopilot、LoopCV、AIApply、Sonara | 有收入，口碑普遍塌 |
| ③ | **本地浏览器机器人全自动投递** | LazyApply、AIHawk、各类 Easy-Apply bot | **正在死** |
| ④ | 真人 / 半人肉代投 | ApplyPass（$99-199/月）、reverse recruiter（$150-4500/月） | 最赚钱，2026 媒体热点 |

**我们在第 ③ 格。**

## 死因证据（A 级，非传闻）

- **Wonsulting 官方博客自述废弃自研自动投递工具**，理由是「投得多不等于面试多」——做这门生意的人自己说这门生意不成立。
- **AIHawk**（2.96 万 star，赛道旗舰）2026-05-17 被作者归档。
- **Sonara** 2024-02-01 融资失败突然停服，后被 BOLD 收购。
- **JobFunnel** 归档说明写明死于各站反自动化。
- 雇主侧：**Greenhouse Real Talent** 2025-06 与 CLEAR 合作上候选人身份核验。

四条独立线索同向。

## 官方 API 路线已堵死（A 级）

Greenhouse Job Board API 的投递 POST 端点**需雇主侧 API key**，求职者拿不到合法批量通道。故全市场都在灰色地带，只是风险落点不同：云端代投风险在服务商 IP、本地机器人风险在**用户账号**、扩展辅助风险最低、人肉零技术风险但不可规模化。

## 最直接的同构对手：career-ops

`github.com/santifer/career-ops` — 开源 MIT、本地优先、跑在 Claude Code/Codex 等命令行里、同样覆盖 Greenhouse/Ashby/Lever。**与我们唯一的差别是它明确宣布不替用户点提交，并把这句话做成了卖点。**

## 对自身的诚实评估

**最高优先级发现**：`confirmed_at` 全 0 —— 183 条历史投递零回音记录。**我们跟被骂的那些产品处在完全相同的无知状态：都不知道自己有没有用。** 谁先测出来谁才有资格谈定位。

**被埋没的四条真实差异点**（目前压在免责声明里，未做卖点）：不碰 LinkedIn/Indeed、数据不出本机、相关性门控、不编造事实。

**合规状态如实**：Greenhouse/Lever/Ashby 对求职者侧自动提交的服务条款原文**搜不到**——主链路的合规性目前建立在「没人明确禁止」而非「明确允许」上。

## 尚未拍板的关键问题（不定则产品定位无法定）

**拍板人对「机器替学生点提交」的风险偏好是什么？** 风险落在学生的账号上，不是我们的服务器上。
